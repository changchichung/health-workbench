HealthWorkbench 個人健康資料工作台（Windows）
==================================================

把健保「健康存摺」與 Apple 健康的下載檔，整理成可累積、可搜尋、
可帶去回診討論的本機健康紀錄。全程本機，不需要帳號，不上傳雲端。


一、安裝
--------------------------------------------------

兩種安裝檔任選一個，內容相同：

  HealthWorkbench_x.y.z_x64-setup.exe   一般安裝程式
  HealthWorkbench_x.y.z_x64_en-US.msi   企業部署常用格式

雙擊執行即可，安裝完成後在「開始」功能表找到 HealthWorkbench。


二、第一次執行（重要）
--------------------------------------------------

本程式尚未購買程式碼簽章憑證，Windows 會顯示藍色的
「Microsoft Defender SmartScreen 已阻止一個無法辨識的應用程式啟動」。

放行方式（只需做一次）：

  1. 點視窗裡的「其他資訊」
  2. 出現「發行者：不明」與檔名後，點「仍要執行」

如果是從瀏覽器下載後直接開啟被擋，也可以：

  在檔案總管對安裝檔按右鍵 → 內容 → 一般頁籤最下方
  勾選「解除封鎖」→ 確定 → 再雙擊安裝


三、怎麼用（三步）
--------------------------------------------------

1. 下載自己的資料

   健保：登入健康存摺（myhealthbank.nhi.gov.tw），
         下載「醫療類」資料，建議選 JSON（內容比 XML 完整）
   Apple：iPhone 健康 App → 右上角個人頭像 →
          匯出所有健康資料 → 把檔案傳到這台電腦

2. 匯入

   打開 App，把檔案拖進視窗（或點「選擇要匯入的檔案」），
   並選擇這份資料屬於哪一位家庭成員。
   格式自動判別，重複的內容自動跳過，所以每隔一段時間
   把新下載的檔案再匯一次即可，資料只會越來越完整。

3. 檢視與分享

   「資料檢視」分頁就是完整的儀表板：總覽、就醫時間軸、
   用藥清單（附成分與官方仿單連結）、檢驗趨勢、全文搜尋。

   要帶去診間或給家人看，可以匯出成獨立檔案，有兩種格式，
   內容一樣，差別只在用什麼開：

     匯出單檔 HTML   這台電腦用，瀏覽器直接開
     匯出 EPUB       電子書格式，傳到手機、平板上看最方便

   這台電腦上看用 HTML 最省事（瀏覽器直接開）。要帶到手機、
   平板上看的話請用 EPUB：iOS 沒辦法用 Safari 或 Chrome 開啟
   本機 HTML 檔案，「檔案」App 的預覽也不執行網頁程式，只會
   一直停在「載入中」，而 EPUB 用內建的 Apple Books 就能直接
   開，字級也能自己調。

   EPUB 要挑會執行網頁程式的閱讀器。匯出檔裡的摺疊、搜尋與
   趨勢圖需要閱讀器支援 EPUB 3 的 scripted content，多數閱讀器
   不支援（支援 EPUB 3 不等於支援 scripted content）。實測可用：
   Apple Books（Mac 與 iPhone）、Thorium Reader（Windows 上也
   能用）、Android 的 Reasily；Google Play Books 實測不執行，
   只會顯示一行提示。

   把 EPUB 加進 Apple Books 時要留意：只要那台裝置的 Books
   iCloud 同步是開著的，這份檔案就會在 iCloud 有備份。只想留
   在裝置上的話，先到「設定 → 你的名字 → iCloud → 顯示全部
   → 圖書」關掉，再把檔案加進 Books。

   兩種格式都含有完整個人醫療資料，請自行妥善保管。


四、你的資料存在哪裡
--------------------------------------------------

  %APPDATA%\com.notoriouslab.healthworkbench\

（在檔案總管的位址欄直接貼上這行按 Enter 就會打開；完整路徑是
  C:\Users\你的帳號\AppData\Roaming\com.notoriouslab.healthworkbench\）

檢視資料的過程不需要網路，也不會對外連線；只有點擊藥品仿單
這類外部連結時才會開啟瀏覽器。
想整批清除，把上面這個資料夾刪掉就結束了。
移除程式請用「設定 → 應用程式 → 已安裝的應用程式」。

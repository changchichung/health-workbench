# app-import-gui — 匯入操作介面

## ADDED Requirements

### Requirement: 選檔與拖放匯入

使用者 MUST 能以系統選檔對話框或拖放檔案至視窗啟動匯入；格式由引擎
自動判型，使用者 MUST NOT 需要指定檔案類型。無法識別的檔案 MUST
顯示支援格式清單（自 adapter 註冊表產生）。

#### Scenario: 拖放匯入
- **WHEN** 使用者將健保 JSON 檔拖入視窗
- **THEN** 顯示判型結果（健保存摺醫療類 JSON）與確認鈕，確認後開始匯入

#### Scenario: 不支援的檔案
- **WHEN** 使用者拖入一張照片
- **THEN** 顯示「無法識別」與目前支援格式清單，不進入匯入流程

### Requirement: 進度與結果報告

匯入中 MUST 顯示進度（百分比＋已處理筆數）；完成後 MUST 顯示增量
結果報告卡：各節區筆數、新增/重複（冪等跳過）統計、品質旗標摘要、
未對照項提示，結構沿用既有增量品質報告。

#### Scenario: 匯入完成報告
- **WHEN** 匯入一份含新資料與重複資料的健保 JSON
- **THEN** 報告卡顯示各節區新增與跳過筆數，與 CLI 版增量報告數字一致

#### Scenario: 匯入中防重入
- **WHEN** 匯入進行中
- **THEN** 再次拖入檔案被拒並提示等待，檢視頁資料維持匯入前狀態直到
  完成（單交易）

### Requirement: 防護情境的使用者呈現

重複檔案（SHA-256 相同）MUST 顯示「已於某時匯入過」並跳過；歸戶防護
（遮罩身分證不符）MUST 顯示不符說明並零寫入；部分失敗續行（對齊
health-database schema v3 契約）MUST 呈現「成功節區/失敗節區」明細，
失敗明細可展開。

#### Scenario: 重複檔案
- **WHEN** 拖入一份先前已匯入的檔案
- **THEN** 顯示原匯入時間並跳過，資料庫零寫入

#### Scenario: 歸戶不符
- **WHEN** 匯入檔 b1.1 與資料庫 profile 遮罩身分證不符
- **THEN** 顯示兩者遮罩值與中止說明，資料庫零寫入

#### Scenario: 部分失敗續行
- **WHEN** 某節區含 5 筆無法解析的紀錄，其餘節區正常
- **THEN** 正常節區完成匯入，報告卡標示失敗節區與筆數，展開可見
  逐筆錯誤摘要

`shape.json` 是 payload 契約的 SSOT，原本沒有 `cpap` —— 契約沒跟上實作，
日後移除該區塊不會被任何檢查抓到。已補入頂層必要鍵與子欄位要求。

體積門檻；沒有 CPAP 資料時仍為合法產物（`cpap` 為空區塊而非缺鍵）。

二、JSON的符號表示方式
  「,」 : 半形的逗號為物件或資料的區隔符號。
  有定義的資料表示，使用「"Key": value 」格式儲存在文件，
  其中：
     ⚫ 「"Key"」為資料名稱，必需為字串。
    ⚫   「:」 為資料名稱與值的間隔符號。
    ⚫   「value」為資料值，可以為字串、數字、物件、集合、布林值或
        空值。
  字串：需要有半形雙引號將此字串框起來表示如 "臺北業務組"。
  數字 : 只能使用半型數字或小數點, 不能有逗號 如: 12345.67。
  布林 : 用英文 true false 來表示布林值(不必有雙引號)。
  空值 : 用英文 null 來表示空值(不必有雙引號)。
  { } :表示物件，物件可以包含物件、集合或資料。
  [ ] :表示集合，多個相同型態物件或值(value)可用此符號框起來。


  **JSON 文件本身就是一個物件, 所以用 " { " 開始; 用 " } "結束

四、資料型態格式說明
資料型態           符號    說明
文數字            X     1.包含 A-z、0-9、空字串、其它符號等。
                     例如：資料格式為文字且長度為 2，則公告之格式表示
                     方式為 X(2)。
數值             9     1.包含 0-9、小數點(.)。
                     2.若資料格式為整數且長度為 10，則格式表示方式為
                     9(10)。
                     若資料格式為整數長度為 3、小數長度為 2，其總長度
                     為 6，則表示方式為 9(6)，並增加說明各個長度(整數
                     長度.小數長度)，如(999.99)。
